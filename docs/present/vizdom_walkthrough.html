VizDOM walkthrough

How a test step travels through VizDOM, one message at a time: the screen becomes a Visual DOM once, every locator is a query over it, and a check for something that is not there fails by construction. Each dashed box on the map is one process; a message that crosses a box crosses a gRPC boundary when the boxes sit on different machines. Pick a scenario, then step with Next, the arrow keys or Play.
