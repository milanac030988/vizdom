## VizDOM 0.2.3

### Highlights

**VizDOM Studio for Linux.** Studio now comes as an AppImage and a .deb for 64-bit Linux (x86-64, glibc 2.35 or newer, such as Ubuntu 22.04 and later), next to the Windows installer.

- Like the Windows installer, it brings Studio, its own Python 3.12 with the VizDOM engine and the Robot Framework library (`Library    VisualGuiLibrary`), CPU-only PyTorch and the EasyOCR English models, so the first analysis works offline.
- Tesseract is not included. The .deb recommends the distribution's `tesseract-ocr` package, so `apt` installs it with Studio. With the AppImage, install it yourself (`sudo apt install tesseract-ocr`); EasyOCR works without it.
- Settings, sessions and plugins go to `~/Documents/VizDOM`.
- Run Robot suites with the Python the .deb installed: `"/opt/VizDOM Studio/resources/python/bin/python3" -m robot my_tests/`
- To use the library from another Python on Linux, install the Python package: `pip install "vizdom[robot]"`.

### Install or upgrade

- **Windows:** download and run `VizDOM-Studio-Setup-0.2.3.exe` below.
- **Linux (.deb, recommended):** download `VizDOM-Studio-0.2.3-amd64.deb` below, then `sudo apt install ./VizDOM-Studio-0.2.3-amd64.deb`
- **Linux (AppImage):** download `VizDOM-Studio-0.2.3-x86_64.AppImage` below, then `chmod +x VizDOM-Studio-0.2.3-x86_64.AppImage && ./VizDOM-Studio-0.2.3-x86_64.AppImage`
- **Python library:** `pip install --upgrade "vizdom[robot]==0.2.3"`

### Known issues

- Capture and input on Linux need an X11 session. On Wayland, log in with *Ubuntu on Xorg*.
- The AppImage needs FUSE 2: `sudo apt install libfuse2` (on Ubuntu 24.04: `libfuse2t64`).
- On Ubuntu 24.04 the AppImage may stop at a sandbox error; use the .deb there.
- The Linux packages are new in this release and have had less testing than the Windows installer. Please report problems on [GitHub](https://github.com/milanac030988/vizdom/issues).
- On Python 3.13, pip installs `opencv-python` 5.x, a major version VizDOM has not been tested with yet. If you see image-processing errors, install `"opencv-python<5"` into the same Python.
