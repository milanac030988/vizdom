## VizDOM 0.2.2

### Highlights

**VizDOM Studio installer can set up your own Python for Robot Framework.**
A new, optional *Python for Robot Framework* page installs the VizDOM Robot
Framework library (`Library    VisualGuiLibrary`) into a Python you already use
for your test suites, so you don't have to run pip yourself.

- The page lists the Pythons it finds: RobotFramework AIO, the ones the `py`
  launcher knows and `python` on the PATH. You can also browse to any other
  `python.exe`.
- For the selected Python it shows the version and whether VizDOM is already
  installed. It accepts 64-bit Python 3.9 to 3.13.
- It installs the VizDOM wheel shipped with the installer (`vizdom[robot]`).
  If that fails, it falls back to the same version from PyPI. Afterwards it
  checks that `import VisualGuiLibrary` works.
- If RobotFramework AIO is installed, it is selected by default. Untick the box
  to skip this step.
- A silent install (`/S`) never changes another Python. Uninstalling Studio
  leaves the installed packages in place.
- Packages already in that Python are kept, VizDOM only adds what is missing.
  The step needs a network connection and downloads about 1 GB (PyTorch, EasyOCR
  and their dependencies).

**`vizdom[robot]` now installs into environments with newer gRPC.**
The `grpc` extra no longer caps `grpcio` and allows `protobuf` up to 6.x, so
pip keeps the `grpcio` and `protobuf` already present (for example in
RobotFramework AIO, Python 3.13) instead of downgrading them or building an old
`grpcio` from source. The gRPC stubs in the wheel were checked with
`grpcio` 1.80 and `protobuf` 6.33.

### Documentation

- New deployment diagram showing a distributed setup: test runners, a shared GPU
  host, and targets on a PC, Android, or a closed device driven by a camera and
  a robot arm.
- Home page rewritten around the problems VizDOM solves, with an interactive
  system overview (one diagram per part, zoom, full window, fitted to the
  window).
- Commands page rewritten from the actual command-line tools; Setup covers the
  three install routes (Studio installer, pip, source).
- Evaluation page shows the real-world and held-out results.
- Outdated pages, paths and ADR statuses fixed.

### Install or upgrade

- **VizDOM Studio:** download and run `VizDOM-Studio-Setup-0.2.2.exe` below.
- **Python library:** `pip install --upgrade "vizdom[robot]==0.2.2"`

### Known issue

On Python 3.13, pip installs `opencv-python` 5.x, a major version VizDOM has not
been tested with yet. If you see image-processing errors, install
`"opencv-python<5"` into the same Python.
